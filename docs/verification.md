使用本地构建后的 Worker 和隐藏浏览器页面，测试数据仅为明确标注“非考试题库”的 4 道人工验收题，没有混入原站内容。测试身份只存在于监听 127.0.0.1 的临时代理中，不属于部署代码。

| 场景 | 实际结果 |
| --- | --- |
| 桌面与 390 × 844 手机视口 | 顶部计时、模块选择、题号抽屉和选项可操作 |
| 判断题答错后打开错题本 | 错题数为 1，进入复习后隐藏旧答案 |
| 错题复习答对 | 错题数变为 0，保留当前反馈，可点击完成复习 |
| 多选题选两个正确项并确认 | 显示回答正确和两个标准选项 |
| 停止本地服务后重新加载页面 | 缓存页面仍打开，题库与已答记录仍可读取 |
| 服务停止期间答单选与填空题 | 两次作答在本地保存，显示待同步 |
| 重启服务并点击同步 | 服务端共收到 5 条事件，包含断开期间新增的两条，页面显示已同步 |
| 再次刷新 | 保留 4/4 完成进度、错题数 0 和作答反馈 |

手机截图保存在本地忽略目录 `outputs/qa/mobile-practice.jpg`。此测试通过停止本地服务模拟请求不可达，没有关闭电脑网络，因此不能替代真实断网、Android 或托管登录验收。恢复网络的事件监听已实现，但本轮恢复步骤使用“点击同步”。
