# 题库浏览器连接核验

日期：2026-10-29。

## 已确认的现象

- Windows 原生窗口控制可以列出 Chrome 窗口，但读取窗口时返回无法可靠识别当前浏览器网址，并自动终止该轮电脑操作。没有证据表明用户缺少权限或原站登录失败。
- 旧 Chrome 标签的浏览器连接曾返回 `Debugger unattached`。重置会话后，在同一个已连接 Chrome 中创建新标签并导航到原站在线练习页，能够读取已登录的七模块列表。
- 通过浏览器接口进入教育学基础会话 `63203`，确认网址为 `/exam/app/train/63203`，题号按钮共 200 个。点击“显示结果”后成功读取首题题干、两项判断选项、标准答案“正确”和原有解析。没有选择答案或提交练习。
- 原站当前主入口脚本为 `/exam/app/assets/index-eb07aa05.js`，来自已加载文档的 `script[src]` 属性。公开练习脚本为 `index-fe0af419.js`。
- 只检查 Chrome 进程的调试启动参数，未发现已有远程调试端口；因此不能直接把现有登录会话交给需要 CDP 地址的 REA 工具。没有重启 Chrome、复制浏览器资料或读取令牌。

## 可用方式和限制

后续优先沿用 Chrome 浏览器连接。旧标签无法附着时可在同一个浏览器中新建标签，沿用登录状态；空的受控标签列表不代表整个浏览器断开。不要为读取网页再调用已失败的原生窗口接口。

浏览器接口已经证实可读取可见题目。当前单次页面读取或点击约需 20 秒，逐题采集完整 1224 题成本较高。页面只挂载当前题，不能把 200 个题号误认为已获取 200 道题目内容。

备用批量导出使用原站已加载的同源请求客户端，只 GET 已观察到的七个练习会话及对应分类名称，核对模块名称和题数后导出白名单题目字段。脚本必须由用户在原站练习页控制台执行；它尚不能算登录响应采集成功。不要通过其他执行通道绕过电脑操作工具的终止，也不要复制认证信息到本地请求。

脚本：`tools/export-all-modules-console.js`。限定当前网址为清单内的已登录练习会话；检查既有主入口脚本及页面挂载后，复用该模块的 `b` 请求客户端。每个模块读取元信息、分类和题目，共 21 次 GET。任何模块名、题量或字段异常均停止，不生成不完整下载。成功时下载 `exam-all-modules-YYYY-MM-DD.json`，输出仅含采集时间、模块名称/分类 ID/会话号及题目字段。

离线验证：`node --experimental-vm-modules --test tools/export-all-modules-console.test.mjs`，17 项通过；`node --check tools/export-all-modules-console.js` 通过。测试需要 VM modules 标志，未带该标志时动态导入的模拟测试不能运行。模拟结果不等于已登录网站执行成功。

独立只读审查未发现阻断正常成功导出的明确缺陷。已确认一项原站行为：复用的客户端遇到 401 会自行记录错误上下文、清除失效登录并转到登录页；导出器不能阻止原站的这个回调，也不承诺失败时页面状态完全不变。模拟测试没有覆盖该原站错误处理，检查的上下文不含请求头或 Authorization。

操作交接：在已登录的练习页打开 F12 → Console，粘贴已提供的脚本并执行。脚本下载后由助手读取本机任务文件；用户不必事先拥有题库文件。若网站报错，保留具体错误信息，不修改认证或浏览器安全设置。
