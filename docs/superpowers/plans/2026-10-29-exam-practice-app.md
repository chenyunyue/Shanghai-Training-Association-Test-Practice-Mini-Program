# 私人考试练习网页实施计划

**目标：**按已批准的设计制作可在 Windows 和安卓使用的私有练习网页，覆盖七个模块，支持离线答题、联网同步、即时解析和自动移出错题本。

**启动条件：**先完成题库采集计划，核对七个模块的题数、题目 ID、题型、答案字段和缺解析数量。实际原站数据尚未取得时，不用截图样例充当完整题库，也不宣称内容或应用已完成。

## 1. 归一化题库

- 只从已核验的七份原始快照导入题目；保留模块名、稳定题目 ID、采集日期和原站答案。
- 在导入边界检查重复 ID、题型、题干、选项、答案指向及总数；将有效题目转成应用使用的固定结构。填空题等具体答案规则由实际响应确定。
- 对比每模块的原站可见题数，输出逐模块导入报告。若有异常题，保留原始记录并单列处理，不静默修正。

## 2. 补全解析

- 保留原站已有解析。逐题筛出缺失解析，写简短、直接对应题干的说明，记录权威来源链接和核验日期。
- 原站答案与来源不一致时，同时标出原站答案与争议依据。无可靠依据时标记“待核实”，不计入完成数。
- 验收时核对缺解析清单已全部补齐，或明确列出尚未完成的题目。

## 3. 私有服务与同步

- 在项目根目录建立 Sites Vinext 应用，保持站点仅所有者可访问。使用 Sites 的 ChatGPT 登录身份，不另建账号系统。
- D1 保存模块、题目和作答事件；服务端以站点用户 ID 限定所有进度读写。题库导入走受保护的一次性流程，不将题目数据放进数据库迁移。
- 每次作答产生唯一事件 ID；同步接口接收本地待上传事件并返回该用户的作答记录。重复上传同一事件只保存一次。错题本按每题最新作答计算，答对即移出。
- 验收：同一账号在两端答题后，联网同步结果一致；重复同步不增加重复作答。

## 4. 答题页面与离线

- 手机顶部紧凑显示模块、时长、进度，题号列表放入抽屉；桌面保持清晰的导航和题目区域。
- 选定答案后立即显示正误、标准答案和解析；复习错题时答对即移出错题本。
- 首次联网成功后缓存页面和题库，IndexedDB 保存题库及待同步作答。断网可继续打开并答题；恢复网络自动重试同步并显示状态。
- 不增加排行榜、提醒或额外复习算法。

## 5. 验证与交付

- 运行题库导入检查、同步去重与错题状态测试、页面构建检查；只对确有风险的行为增加测试。
- 在桌面与手机宽度验证布局、即时反馈和状态提示；发布后实际在安卓浏览器测试首次下载、断网打开、离线答题、恢复网络同步。
- 发布私有 Sites 版本，记录访问网址、题库版本和未验证事项。若安卓真机暂不可用，不把桌面手机视口测试称作真机验收。
