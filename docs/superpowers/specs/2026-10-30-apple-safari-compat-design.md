# macOS 与 iOS Safari 兼容设计

日期：2026-10-30

## 目标与已确认范围

保留现有私人网页/PWA，不制作原生应用。目标是 macOS Safari，以及 iOS Safari 15.4 起的浏览器与“加入主屏幕”入口。练习、错题、模拟测试、离线使用和联网同步的既有行为保持一致。完善现有 `README.md`，说明项目用途、使用方式、安装、开发和实际验证范围。

用户已确认目标 GitHub 仓库可以接收现有 Git 历史及已跟踪的补充解析。原始题库快照和归一化题库仍位于被忽略的 `data/raw/`，不推送。现有 Sites 网站继续保持仅所有者可访问。

## 现状与取舍

活跃页面主要使用自写 CSS，但构建仍导入 Tailwind 4、动画和 shadcn 样式；Tailwind 4、Vite 8 默认目标及 Next 16 官方支持范围从 Safari 16.4 起。现有 WebKit API（原生对话框、动态视口高度等）与 iOS 15.4 的能力大体吻合，但这不证明完整框架和私有登录在 15.4 可用。

选择保留现有应用结构，移除活跃页面未使用的样式导入，明确设置客户端生产构建目标为 Safari/iOS 15.4，并补齐苹果安装所需的图标和元信息。这样改动局限于兼容入口和文档。备选的整套框架降级改动更大且会影响现有托管；仅把最低版本改成 16.4 又不满足本次要求。

## 页面、数据与安装行为

- 保留现有 manifest、服务工作线程、IndexedDB 题库/作答/试卷和 D1 同步接口；不改题目、判分或账号权限。
- 为苹果浏览器提供主屏幕图标与独立网页模式元信息；把页面上的安卓专属安装提示扩展为 Android 与 iPhone/Mac 的对应入口。
- Safari 页面与新安装的主屏幕/程序坞应用不共享 IndexedDB 数据。安装后的首次打开需联网登录并下载题库；已同步的作答可从服务器合并，未同步作答及未交试卷不能直接迁移。`README.md` 明确说明此行为。
- 继续只在一次成功联网访问和题库下载之后提供离线使用。浏览器清理站点数据后需要重新下载。

## 验收与限制

1. 现有 Node 测试、TypeScript 检查和生产构建通过；客户端产物不再包含由未使用的 Tailwind 入口引入的 Safari 16.4 专用样式，构建目标明确包含 Safari/iOS 15.4。
2. 页面仍具备 manifest、苹果图标和独立网页模式信息；练习与模拟测试的安装说明和 README 与实际行为一致。
3. 使用可用浏览器检查页面加载、答题、模拟交卷、刷新恢复、离线打开及恢复同步；部署到原有私人 Sites 网站后核对其访问范围和发布结果。
4. 将完成的代码及文档推送到指定 GitHub 仓库。保留现有历史和已跟踪的补充解析，不把忽略目录中的原始题库或本地凭据加入 Git。

本机没有 macOS/iOS 设备或对应版本模拟器。即使静态检查、Windows 浏览器测试和托管发布通过，仍须在实际 iOS 15.4 与 macOS Safari 上验收登录、安装、离线、作答及同步；交付说明不能把这部分写成已通过。
