# 私人考试练习网页设计

日期：2026-10-29

## 目标与范围

为用户制作一个私有的响应式练习网页，覆盖原站当前登录账号可见的全部 7 个练习模块。Windows 电脑和安卓手机使用同一网址、同一 ChatGPT 账号；首次联网下载题库后可离线练习，恢复网络时自动同步进度和错题记录。页面只服务用户本人，不公开题库。

原站页面仅作为题目、选项、标准答案和已有解析的来源。新网页不调用原站账号执行练习，也不保存原站密码或登录令牌。题库是迁移时取得的版本快照；原站后来变动时，必须另行核对并更新快照。

## 已确认的练习行为

1. 手机端把模块名称、练习时长和进度放在顶部紧凑栏。题号列表收进抽屉；题目和大尺寸选项占据主要空间。电脑端顶部显示时长，模块导航和题号列表可常驻。采用用户确认的布局草图。
2. 每题选定答案后立即显示对错、原站标准答案和解析，然后可进入下一题。允许返回查看已答题，但同一题再次作答以最新一次结果更新错题状态。
3. 答错的题进入错题本。错题本可按模块打开并重新作答；后来答对时自动移出。仍保留作答记录供进度同步，不增加间隔复习、排行榜或提醒。
4. 本地先保存作答。联网后把尚未同步的作答传给服务器，再拉取同一账号在其他设备上的记录。界面显示离线、待同步和已同步状态；同步失败时保留本地记录并在下次联网重试。

## 题库取得与解析

实施的第一个核验点是读取一个模块的实际响应，确认题目、选项、标准答案、已有解析、稳定题目 ID 和总数均可取得。原站公开练习页脚本显示进入模块会请求整份 `questions` 列表，并使用 `questionOptions[].isAnswer`、`answer` 和 `answerKeywords` 渲染答案与解析；登录后的实际响应尚未核验。公开操作手册未说明导出功能，不能据此断言没有导出功能。

核验通过后，逐模块建立原题快照，保存原站模块名、题目 ID、题型、题干、选项、标准答案、原有解析和采集日期。导入时一次性检查外部数据结构、重复 ID、答案是否指向有效选项，并与原站题数核对；内部使用已验证的数据类型，不在各层重复检查。

原有解析原样保留。对于缺失解析，补写简短、针对题干的说明，并附可核查的权威来源及核验日期；以考试大纲和相关原始资料为优先依据。若原站标准答案与可靠资料冲突，保留“原站标准答案”并明确标注争议和依据，不悄悄改答案。未找到可靠依据的题目标记为“待核实”，不编造解释，也不计入内容完成数。

示例：截图中的科学素养第 199 题，原站答案 B《本草纲目》；国家博物馆资料支持“李时珍编撰，1578 年完成”的解析。1578 年应表述为完成时间，不写成出版时间。

## 技术结构与数据流

- **私有托管**：使用 Sites 的私有访问和 ChatGPT 登录。服务器根据稳定的站点用户 ID 读写该用户的进度；题库和作答记录保存在站点数据库。
- **离线端**：渐进式网页应用缓存页面资源和已下载题库；浏览器本地数据库保存题库与作答。离线功能以至少一次成功联网登录和下载为前提。
- **同步**：每次作答生成唯一记录；重复上传同一记录不产生重复作答。错题本由每题最新作答结果生成。无需额外的账户系统或原站凭据。
- **内容版本**：每份题库带版本与采集日期。客户端更新题库时保留作答记录；题目 ID 发生变化时先核对映射，避免把旧错题错误地关联到新题。

## 验收标准

1. 七个模块的题数及逐题题干、选项、标准答案，与迁移时原站可见内容核对一致；记录每模块采集数量和缺解析数量。
2. 所有缺失解析均有经过核验的补充说明和来源。若存在待核实题目，只能作为未完成项报告，不能宣称内容已全部补齐。
3. Windows 桌面和安卓手机宽度的页面均可顺畅答题：顶部计时可见，题号列表不挤占手机答题空间；答题后立即反馈；错题进入错题本，答对后移出。
4. 首次联网下载后断网仍能打开网页并答题；恢复网络后，两端使用同一账号可看到相同进度和错题状态，且作答不丢失。
5. 发布后实际安卓浏览器仍需做一次设备验收。桌面浏览器的手机视口测试只能验证布局，不能代替真实安卓安装、离线存储和同步验证。

## 已知限制与阻断条件

- 目前只有原站公开脚本表明整份题目可能一次返回，尚未验证登录后的数据、各模块题数、答案完整性或是否允许无副作用地批量读取。若核验失败，停止批量迁移并向用户说明所需的官方导出或替代数据来源。
- 离线使用依赖设备浏览器保留本地数据；清除站点数据或首次使用前未下载题库时，需要重新联网。
- 网站托管或登录服务不可用时，新设备无法首次登录；已有本地缓存的设备仍可按离线能力练习。
- 不对原站答案的学术正确性作未经核验的保证；争议题按上面的双重标注规则处理。
